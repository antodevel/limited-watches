# КОСМОС — Время за пределами

Промо-экспозиция двух лимитированных моделей: Next.js App Router, React, TypeScript, Tailwind CSS 4, GSAP и ScrollTrigger. Сайт экспортируется статически в `out/` для Sites.

## Разработка

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm run build
```

`next/image` используется для всех product assets. На статическом хостинге изображения подготовлены заранее; серверный image optimizer не требуется. Только hero-model загружается с preload, остальные изображения ленивые. Два product WebP весят суммарно около 87 KB.

## Scroll-сцены

1. Hero: появление за 1.8 секунды, закреплённое приближение к циферблату и затемнение.
2. Орбитальная история: прорисовка SVG и три последовательные главы.
3. Архитектура часов: закреплённый объект и четыре сменяющиеся выноски.
4. Две модели: симметричная экспозиция; hover, focus и tap меняют световой акцент и описание.
5. Макро: закреплённый crop MODEL 02, медленное увеличение и смещение.
6. КОСМОС: типографический переход с масштабом и CSS clip-path.
7. Limited edition: спокойное проявление часов и финальная орбита с CTA.

Сцены разделены на компоненты. Контент: `data/`. Движение: `components/ExperienceMotion.tsx`, регистрация плагина: `lib/animations/gsap.ts`.

## Доступность и адаптивность

На ширинах до 767 px отключено pinning, выноски показаны последовательно, орбита упрощена. При `prefers-reduced-motion: reduce` GSAP-сцены не создаются, все описания видимы, CSS transitions отключены. Без JavaScript содержимое также читаемо. Меню поддерживает Escape и возврат фокуса. Переключение моделей работает клавиатурой и касанием.

`gsap.matchMedia()` пересоздаёт сцены на переходе через breakpoint и при смене системной motion preference. `mm.revert()` удаляет только анимации и ScrollTrigger этого компонента. Изменение размеров обновляет pinning, после загрузки шрифтов выполняется refresh.
