# КОСМОС — Время за пределами

Независимый визуальный концепт с двумя вымышленными моделями часов.
Next.js App Router, React, TypeScript, Tailwind CSS 4, GSAP и ScrollTrigger.
Статический экспорт: out/.

## Ручной запуск локального сервера

Нужны Node.js и npm. Проект проверен с Node.js 24.19.0 и npm 11.17.0.
Команды ниже выполняются в PowerShell или терминале Windows.

1. Откройте папку проекта:

   ```powershell
   cd "C:\Users\Anton\Desktop\Sites\CosmoWatches"
   ```

2. При первом запуске или после изменения `package-lock.json` установите зависимости:

   ```powershell
   npm ci
   ```

3. Запустите сервер разработки:

   ```powershell
   npm run dev
   ```

4. Дождитесь сообщения `Ready` и откройте [http://localhost:3000](http://localhost:3000)
   в браузере. Изменения файлов подхватываются автоматически.

Оставляйте терминал открытым, пока пользуетесь сайтом. Для остановки нажмите
**Ctrl+C** в этом терминале. Для повторного запуска снова выполните `npm run dev`.
После перезагрузки компьютера сервер нужно запускать заново.

Если порт 3000 занят, используйте другой порт:

```powershell
npm run dev -- --port 3002
```

В этом случае адрес — [http://localhost:3002](http://localhost:3002).
Всегда сверяйтесь со строкой `Local` в выводе сервера.
Если PowerShell блокирует запуск `npm.ps1`, используйте `npm.cmd` вместо `npm`
(например, `npm.cmd run dev`).

Команда разработки слушает `0.0.0.0`: сайт также доступен с других устройств
в той же локальной сети по адресу `http://<IPv4-адрес-компьютера>:3000`, если
сетевые настройки разрешают подключение. Адрес компьютера можно посмотреть
командой `ipconfig`. На телефоне `localhost` означает сам телефон, а не этот ПК.

## Проверки и сборка

```powershell
npm run lint
npm run typecheck
npm run build
```

Сборка создаёт готовый статический сайт в `out/`. В проекте включён
`output: 'export'`, поэтому `npm start` (`next start`) для этой конфигурации
не используется. Для локальной работы запускайте `npm run dev`; каталог `out/`
предназначен для размещения на статическом HTTP-хостинге.

Изображения подготовлены заранее: next/image работает без серверного оптимизатора.
Только hero-model загружается с preload; остальные изображения ленивые.
Два новых AI-концепта: 948 × 1659, прозрачный фон, суммарно около 350 KiB в WebP.

## Scroll-сцены

1. Hero: свет и появление объекта; на десктопе приближение к циферблату.
2. Орбитальный рассказ: прорисовка SVG и три концептуальные главы.
3. Архитектура часов: закреплённый объект и четыре сменяющиеся выноски.
4. Две модели: hover, focus и tap меняют световой акцент и описание.
5. Макро: крупный фрагмент MODEL 02, увеличение и смещение.
6. КОСМОС: типографический переход с масштабированием и clip-path.
7. Вне времени: проявление часов, спокойный финал, внутренние CTA.

## Адаптивность и движение

Закреплённые сцены создаются только при ширине от 1024 px, высоте от 700 px,
точном указателе и поддержке hover. На остальных экранах — естественный
вертикальный поток; текст не скрывается. Быстрая прокрутка не ставит анимации
в очередь: scrub:true напрямую связывает изображение с текущей позицией.

На десктопе текст раскрывается внизу viewport и полностью виден на отметке
86% высоты окна. Начальное проявление часов сразу завершается при прокрутке.
Все pin-сцены создаются по порядку перед измерением reveal-триггеров.
Панели деталей переходят друг в друга без пустых интервалов.

prefers-reduced-motion отключает GSAP и CSS transitions; все описания видимы.
Без JavaScript контент тоже читаем. gsap.matchMedia пересоздаёт сцены при
смене условий и очищает анимации, pinning, служебный класс и слушатели.

Контент: data/. Большие сцены: lib/animations/scenes.ts.
Адаптивные эффекты: components/ExperienceMotion.tsx.
Материалы: docs/CONTENT.md. Проверки: docs/QA.md.

## Баннер AntoDev

Готовый баннер интегрирован из ../_ASSETS/demo-banner в components/DemoBanner.tsx
и components/demo-banner.css, подключён в app/layout.tsx. Ссылка открывает
https://antodev.vercel.app/ в новой вкладке. Крестик скрывает панель до обновления
страницы; localStorage, sessionStorage и cookies не используются. Шапка сайта
сдвигается под баннер и возвращается наверх после закрытия.
